# MyCommander2

This is a Midnight Commander like file manager for MacOS 27+ writen in Swift. The idea first is to compare files using [Meld](https://gitlab.gnome.org/GNOME/meld).

## Keyboard shortcuts

- CMD + F (filter the list)
- CMD + Y (compare files and directories using Meld)
- CMD + L (synchronize both panels to a specific directory view)
- CMD + Enter (insert the name of the current item into the command line)
- CMD + 1–8 (functions found in the bottom menu)
- CMD + Shift + 2 (compare directories)
- Backspace (go to parent directory)

### In the built-in text editor:

- CMD + S (save changes)
